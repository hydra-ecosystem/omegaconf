# Security

Report security vulnerabilities privately through
[GitHub Security Advisories](https://github.com/hydra-ecosystem/omegaconf/security/advisories/new).
Do not file a public issue or pull request for a suspected security vulnerability.

OmegaConf will request CVEs for vulnerabilities assessed as Medium severity or higher.
Low-severity vulnerabilities may be fixed and documented in a security advisory
without requesting a CVE.
